# kite3d

The Kite3D command creates and develops browser 3D games. It also points agents to bundled procedures for tasks such as releasing a game.

```sh
npx kite3d init my-game
cd my-game
npm install
npx kite3d dev
```

For the full command list and project guide, run `npx kite3d` or read the generated `AGENTS.md`.

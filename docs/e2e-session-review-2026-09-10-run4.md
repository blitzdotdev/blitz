### The Git rule

`AGENTS.md:18` says initialization does not create a nested repository when the project folder is already inside one. The rule is right for a project inside a real monorepo and wrong here. The home directory is a repository that does not track `blitz-games`, `init` said nothing, `doctor` passed, and the guide's `checkpoint` and `restore` would have written commits into `blitzdotdev/blitz-mac`. A better rule: create the nested repository unless the parent repository already tracks files under the project folder; always print which repository will hold checkpoints; make `doctor` warn when the repository root differs from the project root; make `checkpoint` and `restore` refuse a parent repository unless the user opts in. See I2.
